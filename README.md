# Playmate Sock Dolls - Ecommerce Application Prototype

A complete frontend ecommerce prototype built independently for the Playmate Sock Dolls case study. This project demonstrates a full online ordering workflow, including product browsing, customer account setup, persistent cart management, checkout, shipping/tax calculation, payment validation, and order confirmation. Designed to showcase practical UI/UX design and functional frontend logic using HTML, CSS, and JavaScript.

# Features
- Product browsing with dynamic pricing and line totals
- New customer setup and returning customer login
- Persistent shopping cart using LocalStorage
- Quantity updates, item removal, and real‑time totals
- Checkout with billing/shipping forms and autofill
- ZIP‑based shipping calculation + expedited option
- Payment validation (prototype)

# Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- GitHub Pages (deployment)

# Project Purpose

Built as a systems analysis and implementation prototype to demonstrate a complete ecommerce workflow for a children’s hospital ordering system. Focused on frontend logic, user experience, and practical application of web development fundamentals.
